# Code of Conduct

We are committed to a welcoming, respectful, and constructive community.

Examples of behavior that contribute to a positive environment include being considerate, giving and receiving feedback gracefully, and focusing on what is best for the community. Harassment, discrimination, personal attacks, and publishing another person's private information are not acceptable.

Project maintainers may remove, edit, or reject contributions that do not follow this Code of Conduct. For private concerns, contact a maintainer through GitHub.
